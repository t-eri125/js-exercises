## 問題 4.5

以下のプログラムは 1 から 100 までの FizzBuzz を出力する。<br>
Fizz、Buzz、FizzBuzz、数値、それぞれのケースで式がどのように評価されるか言及しつつ処理を説明しなさい。
```js
for (i = 1; i < 101; i++)
  console.log((i % 3 ? "" : "Fizz") + (i % 5 ? "" : "Buzz") || i);
```

### 回答
iの値が1から始まり、まず論理演算式の左辺の式が評価される。<br>
論理演算式は、左辺がtrueならば左辺の値が返され、falseならば右辺のオペランドが返される。<br>
```js
(i % 3 ? "" : "Fizz") + (i % 5 ? "" : "Buzz")
```
まず、左辺の中で`i%3`を評価し、true(0ではない)ならば`""(空文字)`、falseならば`Fizz`を追加する。<br>
次に、左辺の中で`i%5`を評価し、true(0ではない)ならば`""(空文字)`、falseならば`Buzz`を、先ほどの文字列の後に追加する。<br>

上記の結果、`""`ではなく評価がtrueであればそのまま文字列を返し、`""`で評価がfalseであれば右辺の式の評価に移る。

```js
i
```
左辺の式の評価がfalseの場合、右辺はfor文内で`i`は1～100と決まっており必ずtrueになるため、`i`を返す。

---
#### Fizz
論理和演算子の左辺の式内で1つめの項でfalse、2つ目の項でtrueの結果が返され、左辺の式がtrueとなることで出力される

1. `i%3`の値が偽（0）　　　　→　結果に"Fizz"が追加
2. `i%5`の値が真（0ではない）→　結果に""（空文字）が追加
3. 上記1～2の結果、論理和演算子の左辺の式は`Fizz`で評価がtrue<br>
→　論理和演算子の左辺の式をそのまま返し、右辺の式は評価しない

#### Buzz
論理和演算子の左辺の式内で1つめの項でtrue、2つ目の項でfalseの結果が返され、左辺の式がtrueとなることで出力される

1. `i%3`の値が真（0ではない）→　結果に""（空文字）が追加
2. `i%5`の値が偽（0）　　　　→　結果に"Buzz"が追加
3. 上記1～2の結果、論理和演算子の左辺の式は`Buzz`で評価がtrue<br>
→　論理和演算子の左辺の式をそのまま返し、右辺の式は評価しない

#### FizzBuzz
論理和演算子の左辺の式内で2項どちらもfalseの結果が返され、左辺の式がtrueとなることで出力される

1. `i%3`の値が偽（0）→　結果に"Fizz"が追加
2. `i%5`の値が偽（0）→　結果にさらに"Buzz"が追加
3. 上記1～2の結果、論理和演算子の左辺の式は`FizzBuzz`で評価がtrue<br>
→　論理和演算子の左辺の式をそのまま返し、右辺の式は評価しない

#### 数値
論理和演算子の左辺の式がfalseになり、右辺の式がtrueになることで、`i`出力される

1. `i%3`の値が真（0ではない）→　結果に""（空文字列）が追加
2. `i%5`の値が真（0ではない）→　結果にさらに""（空文字列）が追加
3. 上記1~2の結果、論理和演算子の左辺の式は空文字で評価がfalse<br>
→　右辺のオペランドを評価し、`i`は1~100でtrueである（0ではない）ため、`i`を返す
