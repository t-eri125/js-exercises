## 回答

ヒント: `push` を $`n`$ 回呼び出したとき、7.10 の実装では配列を倍々にしていくので再配置は $`log_2 n`$ 回発生する。各再配置で要素のコピーは $`1, 2, 4, 8, ..., 2^{log_2 n}`$ 回発生する。再配置の際にコピー回数の総和は $`2^0 + 2^1 + 2^2 + ... + 2^{log_2 n} = ...`$ (等比数列の和の公式を思い出すこと)。この値を $`n`$ で割れば各 `push` の平均時間計算量が求められる。

等比数列 $`2^0 + 2^1 + 2^2 + ... + 2^{log_2 n} = ...`$ は $`2^{k+1} - 1`$
再配置回数 $`k = log_2 n`$ とすると、和は $`2^{log_2 n+1} - 1 = 2n - 1`$ となる 
これが$`O(n)`$であり、これをnで割ると $`(2n - 1) / n = 2 - 1/n`$ のため、平均時間計算量は $`O(1)`$

### 以下の関数 `copyA` と `copyB` に対し、`array.length` を `n` とした時の時間計算量を求めなさい。

copyA：配列の作成は $`O(1) or O(n) だが メモリ確保として O(n)`$ 、ループn回で1回のコピーは $`O(1)`$ なので　$`O(n)`$。これらを足して $`O(n) + O(n) = O(n)`$

copyB：空配列は $`O(1)`$、pushをn回呼ぶと $`O(1) * n = O(n)`$
