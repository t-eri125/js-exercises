## 問題 17.10 🖋

TypeScriptとFlowについて、どちらが主流となっているかを調べなさい。
また、その理由を考えてまとめなさい。

TypeScript が主流（[StackOverflow調査](https://survey.stackoverflow.co/2023/?utm_source=chatgpt.com#section-most-popular-technologies-programming-scripting-and-markup-languages)）。
調べてもflow→typescriptへの移行をしている記事は見つかるが、逆はなさそう。


理由
- 大規模プロジェクト向き:
インターフェース、ユニオン型、ジェネリクスなど幅広い型システムを持っている（型定義・ツールが圧倒的に充実している）ため、大規模プロジェクトに適している。

- IDEとの連携やサポートが充実:
VS Code などのエディタとの相性が良く、多くのライブラリが公式に対応している。
- 業界のトレンド
[State of JS 2020: JavaScript Flavors](https://2020.stateofjs.com/en-US/technologies/javascript-flavors/)　の段階でも、新規プロジェクトで TypeScript を採用するケースが増えていて、流行としても TypeScript への移行するケースが多い。
