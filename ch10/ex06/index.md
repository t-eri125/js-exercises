## 問10.6
エクスポートしないjsファイルを複数回importする場合、import文の前後やimport先のコードの実行順序はどうなりますか。実証コードを作成し、予想してから実行結果を確認しなさい。

### 回答
#### 予想
import文が最初に1度だけ実行され、その後はimport文以外が上から順に実行される。

- p.282 3文5行目「関数宣言と同じように、インポートは先頭に「巻き上げ」られます」
- p.284 2文1行目「このようなモジュールは、最初にインポートされたときに実行されます（その後にインポートされていても何もしません）。」

#### 実行結果
予想と同じ

```powershell
エクスポートしないtsファイルが呼ばれた
import前
import　1回目
import　2回目
import　3回目
```
