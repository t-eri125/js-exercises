# 9.2
また一方で、このようなクラス構造は一般的に良くないとされている。このクラスの問題点を説明しなさい。
```ts
import { C } from "./index.js"; // ts でも可

test("", () => {
  const c = new C();
  expect(c.x).toBe(0);
  expect(c.x).toBe(1);
  expect(c.x).toBe(2);
});
```

### 回答
ゲットするたびに計算を行い値が変化してしまう。
そのため、実行順序や実行回数によって期待する結果が得られなくなる。
また値の取得に見せかけたインクリメントであるため、可読性が良くなく意図しない実装につながりやすくなる。

ゲッターは値を返すだけであるべきなため、メソッドにした方がよい。
