## index.html ファイル内の script タグから type="module" 属性を削除した場合、期待通り動作させるにはどうすべきか答えなさい。

モジュールを指定しないと、スクリプトは HTML のその位置で即時実行される。そのため、head 内に記述すると body 要素はまだ存在しないため、querySelector が null になる

1. script に defer 属性を付ける（p.452より）
2.  `「HTML ドキュメントが完全に読み込まれ解析されたときに、
「DOMContentLoaded」イベントが発生します（p.458）」`
とあるように、DOMContentLoaded 内で呼び出せばモジュール指定と同じタイミングで実行できる。
