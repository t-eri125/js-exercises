# 8.13
### 問題
以下のコードが Web サービスの一部で使われており、引数の input には Web サービスの利用者が入力した文字列が渡されるものとする。

```js
function f(input) {
  const f = new Function(`return "Hello, " + ${input}`);
  console.log(f());
}
```

このコードには重大な問題が含まれている。何が問題と考えられるか記述しなさい。
また問題を実証できるコードも記載しなさい。

### 回答

Web サービスの利用者が入力した文字列（input）がサニタイズされることなくそのまま関数本体に埋め込まれているため、コードインジェクション（JavaScriptのコードを不正に挿入し、実行させる攻撃）ができてしまう。

もしくは、意図しない構文エラーが発生し、サービスが例外で停止する可能性がある。
