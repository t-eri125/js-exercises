## 問11.7
括弧の対応が正しい文字列かどうか判定する正規表現は書けるだろうか。
連続する 2 文字が () である箇所を除去する操作を 0 回以上繰り返して空文字列にできるとき、その文字列は括弧の対応が取れているものとする。
以下の文字列に対してはマッチする:
```
"(()(()))"
"(((())))"
```

以下の文字列に対してはマッチしない:
```
"((())"
"()()())"
```

任意の長さの文字列に対して上記の判定を行う正規表現を書きなさい (書けない場合はその理由を調べて記述しなさい)。


### 回答
任意の長さの文字列に対して括弧の対応が正しいかを判定する正規表現は書けない。

正規表現は、「文字パターンを表現するオブジェクト」である（p309）。
"(()(()))" のような入れ子構造では、内側の括弧を先に空に処理してから残った外側を確認するような再帰的処理が必要になる。
しかし、JavaScriptでは正規表現で文字列を再帰的にたどることはできないため、正規表現だけで「括弧の対応が正しい文字列」を任意長で判定することは不可能である。


（補足）
正規表現は有限オートマトンで扱える文字列パターンしか表現できないが、今回の括弧に関しては入れ子の深さが無限に変化するため、深さを追いきることができない。

有限オートマトン：状態（finite state）と遷移（transition）で文字列を読み取る仕組み。状態の数が有限で、文字列を順番に読んで受理するか拒否するかを決める。
