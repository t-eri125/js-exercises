## 問題 16.12 🖋

用語「C10K問題」について調べて説明しなさい。

**出題範囲 16.10**

### 回答

C10K問題とは、従来の Web サーバーにおいて、
**同時接続数が 10,000 件を超えると、メモリ消費やコンテキストスイッチの増大により性能が著しく低下する問題** のこと。
この問題の原因は、1リクエストごとにプロセスやスレッドを割り当てる設計により、接続数の増加がそのままリソース消費の増加につながるためである。
Node.js のようなイベント駆動・ノンブロッキング I/O を採用したサーバーは、少数のスレッドで多数の接続を処理できるため、C10K問題を回避できる。

より具体的なメモ
```
C10K問題は、1台のサーバーで同時接続数が10,000（10K）を超えると性能が急激に低下する課題を指す。

【問題の原因】
従来の Web サーバー（例：Apache）では、「1リクエスト = 1プロセス / 1スレッド」。
接続数の増加に比例して
- メモリ消費が増大
- コンテキストスイッチが頻発
- OS のファイルディスクリプタ上限に到達
といった問題が発生する。

その結果、CPU やメモリに余裕があっても、同時接続数が増えるだけで新規リクエストを処理できなくなるという状況が生じる。
​
【JavaScriptとの関連】
Node.js は、
- シングルスレッド
- イベント駆動モデル
- ノンブロッキング I/O
- OS の epoll / kqueue などのイベント多重化機構を利用
という設計を採用している。

そのため、多数の接続を 1スレッドで待ち受けたり、処理が可能になったものだけをイベントループで処理したりでき、1プロセスで数万規模の同時接続を効率的に扱える。
この設計により、C10K問題を本質的に回避できる。
​
【解決策の例】
- Nginx のような 非同期・イベント駆動型 Web サーバー
- イベントループ＋ノンブロッキング I/O を用いたアーキテクチャ
- スレッド／プロセスを接続数に比例させない設計
```
